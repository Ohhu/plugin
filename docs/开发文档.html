概念速查

下面 4 个主题覆盖了使用网关时最容易踩坑的点；详细字段说明见后面的接口文档。

认证与 API Key
  • • 浏览器：登录后 qmg_session 与 qmg_csrf Cookie 自动下发； 非 GET 请求需在请求头里带 X-CSRF-Token。
  • • 程序化：在Authorization头中携带 Bearer <api_key>。
  • • API Key 创建后明文 仅返回一次，请妥善保存。
  • • 新创建的 Key 默认继承用户当前套餐。
限流与配额
  • • QPS：按用户套餐限制每秒并发请求数，超限响应 429。
  • • 每日 / 每月配额：免费版默认 100 次/日；超出后若开启 Extra Usage， 将按千次单价从余额扣费。
  • • 软限：达到 softLimitPct 时 前端会提示，但不限流。
余额与超额计费
  • • 通过 POST /v1/billing/balance/topup 创建充值订单，支付成功后金额自动入账。
  • • Extra Usage 开启后，超额请求按千次单价从余额扣费； 可设置月度上限防止意外大额扣费。
  • • 每一次扣费都会写入余额变动明细，可在/v1/billing/balance/transactions 查询。

多平台音乐网关 API

多平台音乐网关

多平台音乐网关 API 是一组用于聚合 QQ 音乐 / 网易云音乐 / 酷狗音乐等多家音乐源的统一 RESTful 接口。 网关在内部完成账号池调度、限流配额、计费扣减、Extra Usage 超额计费、余额扣款等控制逻辑， 上游应用只需要通过统一的 API 接入即可。

协议总览

  • 基础路径：所有业务接口位于 /v1/... 命名空间下。
  • 认证方式：
    • Cookie 会话（前端控制台用）：登录后服务器下发 sid 会话 Cookie。
    • API Key（程序化调用用）：在 Authorization: Bearer <api_key> 请求头中携带。
  • 响应封装：网关接口绝大多数返回 { code, message, data } 包装结构（code = 0 表示成功）， 详情见下方 Response schema 定义。
  • CSRF 保护：使用 Cookie 会话时，所有非 GET/HEAD/OPTIONS 请求都需要在请求头中携带 X-CSRF-Token（值与 Cookie csrf_token 一致）。API Key 模式不受 CSRF 限制。
  • 限流模型：
    • QPS：按用户套餐限制每秒请求数。
    • 每日 / 每月配额：免费版默认 100 次/日；超出后若开启 Extra Usage 则会按千次价从余额中扣费。

错误码

code 含义

404 资源不存在

429 限流（QPS 或日/月配额耗尽）
500 服务器内部错误
